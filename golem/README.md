# GOLEM Ontology

This W3ID provides a persistent identifier for the **GOLEM Ontology of Narrative and Fiction**.

## Identifier

**https://w3id.org/golem/ontology**

## Content Negotiation

The stable identifier supports content negotiation for the following representations:

* **RDF/Turtle:** https://ontology.golemlab.eu/current/golem.ttl
* **RDF/XML (OWL):** https://ontology.golemlab.eu/current/golem.owl
* **JSON-LD:** https://ontology.golemlab.eu/current/golem.jsonld
* **HTML:** https://ontology.golemlab.eu/current/golem.html

HTML is returned as the default representation.
